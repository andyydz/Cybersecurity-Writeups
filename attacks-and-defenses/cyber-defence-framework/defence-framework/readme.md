# Attacks & Defenses — Cyber Frameworks

This folder contains writeups covering foundational cybersecurity frameworks used to understand, model, and communicate about adversary behavior — from attack lifecycle models to the industry-standard knowledge base for tactics and techniques.

## Contents

| Room | Description |
|------|-------------|
| [Cyber Kill Chain](./cyber-kill-chain.md) | Lockheed Martin's 7-stage linear model of an attack, from Reconnaissance to Actions on Objectives. |
| [Unified Kill Chain](./unified-kill-chain.md) | An 18-phase framework (Pols) that expands on the Cyber Kill Chain and MITRE ATT&CK, modeling attacks as a non-linear progression across In → Through → Out stages. |
| [MITRE ATT&CK](./mitre-attack.md) | A globally accessible knowledge base of adversary tactics, techniques, and procedures (TTPs) based on real-world observations, plus related projects like CAR and D3FEND. |

## Why This Matters

These frameworks give defenders a shared, standardized language for describing adversary behavior — enabling consistent threat profiling, detection engineering, and communication across the security community, regardless of which framework an individual analyst or organization starts from.
